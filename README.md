A modern and responsive **SAFF Football Championship** website built with React and modern frontend technologies. The project provides an engaging football-focused experience for exploring **teams, players, matches, standings, tournament information, and football-related content**.

The application focuses on a clean, responsive interface, reusable components, and an interactive user experience across different screen sizes.

## 🏆 Project Overview

**SAFF Football Championship** is a modern football-themed web application designed around the South Asian Football Federation (SAFF) Championship.

The website presents football-related information through a structured and visually engaging interface.

The project includes sections for:

* 🌍 Participating teams
* 👤 Player information
* ⚽ Match information
* 📊 Championship standings
* 📰 Football news and updates
* 🏟️ Team and match details
* 🏆 Tournament information

The interface is designed to make football information easy to explore while maintaining a responsive and modern visual experience.

## 🧩 Component Architecture

The application follows a reusable **React component architecture**.

### `App.tsx`

The main application component responsible for composing the major sections of the application.

### `nav.tsx`

Responsible for the website navigation and primary navigation interface.

### `hero.tsx`

Contains the main hero/banner section that introduces the SAFF Football Championship website.

### `team.tsx`

Responsible for displaying participating team information and team-related content.

### `players.tsx`

Controls the player-related section and player interface.

### `avialableplayers.tsx`

Displays the available player information.

### `cardPlayers.tsx`

Provides the individual player card UI.

### `selectedPloayers.tsx`

Displays selected player information and manages the selected-player interface.

### `footer.tsx`

Contains the website footer and supporting navigation/content.

### `type.ts`

Contains TypeScript types and interfaces used throughout the application.

## 💻 Run the Project Locally

Follow these steps to run the project on your local machine.

### 1. Clone the Repository

```bash
git clone https://github.com/Rumi-Parvez/Saff-Championship-2026.git
```

### 2. Navigate to the Project

```bash
cd Saff-Championship-2026
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

The Vite development server will normally be available at:

```text
http://localhost:5173
```

Open the URL in your browser to view the application.
