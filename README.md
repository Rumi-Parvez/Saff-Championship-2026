# ⚽ SAFF Football Championship

A modern and responsive football championship website built around the **SAFF Football Championship**. The project provides an engaging interface for exploring teams, players, matches, standings, tournament information, and football-related content.

## ✨ Features

* 🏆 SAFF Football Championship information
* 🌍 Participating teams
* 👤 Player information
* ⚽ Match information
* 📊 Championship standings
* 📰 Football news and updates
* 🏟️ Team and match details
* 📱 Fully responsive design
* 🎨 Modern football-themed UI
* 🧩 Reusable components
* ⚡ Smooth and interactive user experience

## 🛠️ Technologies Used

## 💻 Run Locally

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project

```bash
cd saff-football-championship
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

The project will normally run at:

```text
http://localhost:5173
```

## 🚀 Production Build

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
